# Phase Packet: PH-090 — Remote STT Adapter (NVIDIA Multilingual ASR)

## 1. Purpose
Implement the `STTAdapter` to transcribe post-wake command audio segments using NVIDIA's hosted multilingual ASR model (`nvidia/parakeet-1_1b-rnnt-multilingual-asr`). Guarantees post-wake provenance by consuming an internal trusted `CommandAudioSegment` produced by `CommandRecorder`. Connects to NVIDIA's authoritative Riva gRPC service (`grpc.nvcf.nvidia.com:443`) or local Riva NIM container (port 9000). Enforces that in-memory audio buffers and internal `BytesIO` streams are released in a `finally` block, with the coordinator releasing the segment immediately post-transcription.

## 13. Authoritative Service Protocol & Provenance
- **Model Ground Truth:** `STTConfig.model = "nvidia/parakeet-1_1b-rnnt-multilingual-asr"`. This model operates via NVIDIA Riva ASR over gRPC (`grpc.nvcf.nvidia.com:443` or local Riva NIM container `localhost:9000`). It is NOT an OpenAI `/v1/audio/transcriptions` endpoint.
- **Trusted Segment Provenance:** `STTAdapter.transcribe()` accepts ONLY `CommandAudioSegment`. Raw unverified bytes cannot be passed to the adapter.
- **Memory Release Contract:** The adapter maintains no persistent copy of PCM bytes. All internal buffers, streams, and `io.BytesIO` objects are closed and dereferenced in a `finally` block. The coordinator drops its reference to `segment` immediately after `transcribe()` completes.
