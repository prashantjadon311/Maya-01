# Phase Packet: PH-090 — Remote STT Adapter (NVIDIA Multilingual ASR)

## 1. Purpose
Implement the `STTAdapter` to transcribe post-wake command audio segments using NVIDIA's hosted multilingual ASR (Parakeet). Transcriptions support English, Hindi (`hi-IN`), and mixed Hinglish. The adapter strictly enforces that audio buffers are released from memory immediately post-transcription, and that STT failures fail closed with zero downstream action execution.

## 13. Exact Algorithms

### Algorithm: Transcribe Command Audio
1. Validate `0 < len(pcm_bytes) <= 320,000` (max 10s PCM). If invalid, raise `InvalidAudioBufferError`.
2. Wrap PCM in memory WAV container (`io.BytesIO`).
3. Transition `AppState` to `TRANSCRIBING`.
4. Perform non-blocking HTTP POST to NVIDIA STT endpoint with timeout `10.0s`:
   - URL: `https://integrate.api.nvidia.com/v1/audio/transcriptions`
   - Headers: `Authorization: Bearer <NVIDIA_API_KEY>`
   - Form-data: `file=@audio.wav`, `model="nvidia/parakeet-ctc-1.1b-multilingual"`, `language=language`.
5. On HTTP 200:
   a. Parse JSON response extracting `text`.
   b. Clean up: `del pcm_bytes`, explicit `gc.collect()` or release reference.
   c. Return normalized text string.
6. On error or timeout:
   a. Clean up: clear buffer immediately.
   b. Transition `AppState` to `ERROR`.
   c. Raise `STTRecognitionError`. **Zero downstream action executed.**

## 14. Reference Implementation
```python
class STTAdapter:
    def __init__(self, api_key: str, base_url: str):
        self.api_key = api_key
        self.base_url = base_url
        self._client = httpx.AsyncClient(timeout=10.0)

    async def transcribe(self, pcm_bytes: bytes, language: str = "hi-IN") -> str:
        try:
            # Enforce post-wake size limit
            if len(pcm_bytes) > 320000:
                raise ValueError("Audio exceeds 10s limit")
            wav_io = create_wav_bytes(pcm_bytes)
            files = {"file": ("command.wav", wav_io, "audio/wav")}
            data = {"model": "nvidia/parakeet-ctc-1.1b-multilingual", "language": language}
            resp = await self._client.post(self.base_url, files=files, data=data, headers={"Authorization": f"Bearer {self.api_key}"})
            resp.raise_for_status()
            return resp.json()["text"].strip()
        finally:
            self.release_buffer()

    def release_buffer(self) -> None:
        self._active_buffer = None
```

## 15. Concurrency Model
- Sequential transcription: only one voice command transcribed at a time per session.

## 16. Cancellation Behavior
- If cancelled during transcription, the HTTP request is aborted immediately, and audio memory is deallocated.

## 17. Timeout Behavior
- 10.0s hard timeout on STT API calls. Fails closed with `STTTimeoutError`.

## 18. Retry/Idempotency Behavior
- Transient network drops retry once after 500ms backoff. If second attempt fails, abort command.

## 19. Error Behavior
- STT failure transitions system state to `ERROR`, plays audio error tone, and executes zero downstream actions.

## 20. Security Invariants
- **Primary Enforcement:** Only post-wake audio segments (max 10s) sent to STT; pre-wake ring buffer never transmitted.
- **Fail-Closed:** Unrecognized speech or STT network drops result in zero commands dispatched.

## 21. Resource Limits
- Max audio segment: 10.0s (320 KB PCM).
- Memory delta during transcription: < 5 MB. Freed immediately post-call.

## 22. Secrets/Privacy Behavior
- Audio is never saved to persistent storage unless user explicitly enables debug logging in `config.toml`.

## 23. Failure Cases
- No speech detected in audio: STT returns empty string; router takes no action.
- Hosted STT API down: Fails closed, notifies user via desktop notification or tray tooltip.
