# Phase Packet: PH090 — Remote STT Adapter (NVIDIA Multilingual ASR)

## 1. Purpose
Implement the `STTAdapter` to transcribe post-wake command audio segments using NVIDIA's hosted multilingual ASR model (`nvidia/parakeet-1_1b-rnnt-multilingual-asr`). Guarantees post-wake provenance by consuming an internal trusted `CommandAudioSegment` produced by `CommandRecorder`. Connects to NVIDIA's authoritative Riva gRPC service (`grpc.nvcf.nvidia.com:443`) or local Riva service (`localhost:50051`). Enforces that in-memory audio buffers and internal streams are released in a `finally` block, with the coordinator releasing the segment immediately post-transcription.

## 13. Exact Algorithms / Security Invariants
- **Model Ground Truth:** `STTConfig.model = "nvidia/parakeet-1_1b-rnnt-multilingual-asr"`. This model operates via NVIDIA Riva ASR over gRPC (`grpc.nvcf.nvidia.com:443` or local Riva gRPC endpoint `localhost:50051`). It is NOT an OpenAI `/v1/audio/transcriptions` endpoint.
- **Trusted Segment Provenance:** `STTAdapter.transcribe()` accepts ONLY `CommandAudioSegment`. Raw unverified bytes cannot be passed to the adapter.
- **Memory Release Contract:** The adapter maintains no persistent copy of PCM bytes. All internal buffers and streams are closed and dereferenced in a `finally` block. The coordinator drops its reference to `segment` immediately after `transcribe()` completes.
- **Payload Bound:** Audio payload strictly capped at 960,000 bytes (30 seconds of 16 kHz 16-bit mono PCM).

## 14. Reference Implementation / Capsule Guidance
`STTAdapter` connects to Riva ASR gRPC transport. Adapts streaming response deltas to finalized `STTResult`.

## 15. Concurrency Model
Async gRPC transport using HTTP/2 bidirectional streaming over TLS (hosted) or local TCP.

## 16. Cancellation Behavior
Active transcription stream cancelled by calling `call.cancel()` on the gRPC channel upon cancellation request.

## 17. Timeout Behavior
Hard network timeout of 10 seconds for initial connection and 15 seconds for transcription completion.

## 18. Retry / Idempotency Behavior
Transcription requests are idempotent; passing the same audio segment yields equivalent text transcript.

## 19. Error Behavior
gRPC status codes mapped to typed `STTError` exceptions; network failure triggers fallback or error dispatch.

## 20. Security Invariants
STT adapter accepts trusted `CommandAudioSegment` only; pre-wake audio is never forwarded to transcription endpoint.

## 21. Resource Limits
Audio payload strictly capped at 960,000 bytes (30 seconds of 16 kHz 16-bit mono PCM).

## 22. Secrets / Privacy Behavior
Audio data streamed over encrypted TLS; audio buffer cleared from memory immediately upon completion.

## 23. Failure Cases / Edge Cases
- Audio payload exceeds 960,000 bytes: Raises `STTAudioTooLargeError`, closes call without sending.
- Local Riva service unavailable at `localhost:50051`: Catches gRPC error and raises `STTServiceUnavailableError`.
- Cancellation during streaming: Invokes `call.cancel()`, releases internal buffers, and re-raises `asyncio.CancelledError`.
- Empty audio segment (0 bytes): Returns empty transcript immediately without network calls.
