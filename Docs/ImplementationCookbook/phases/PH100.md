# Phase Packet: PH-100 — StatusNotifierItem System Tray Integration

## 1. Purpose
Implement the desktop system tray integration using the freedesktop `StatusNotifierItem` specification over user session D-Bus. Eliminates the need for a heavyweight resident GUI toolkit (e.g. Qt/GTK main loops), keeping idle memory delta under 10 MiB. Exposes live assistant state, Push-to-Talk, Always Listen toggle, Dashboard launcher, Pause, and Quit actions. Decouples system shutdown by receiving an injected asynchronous shutdown callback rather than a concrete lifecycle manager dependency.

## 12. Decoupled Lifecycle Invariant
The tray receives an injected shutdown callback:
```python
class ShutdownCallback(Protocol):
    async def __call__(self) -> None: ...
```
The tray never takes a concrete import dependency on `LifecycleManager` or `app.lifecycle`. When the user selects "Quit", the tray invokes `await self._shutdown_callback()`.
