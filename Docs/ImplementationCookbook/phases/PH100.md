# Phase Packet: PH100 — StatusNotifierItem System Tray Integration

## 1. Purpose
Implement desktop system tray integration using the freedesktop `StatusNotifierItem` specification over user session D-Bus. Eliminates the need for a heavyweight resident GUI toolkit (e.g. Qt/GTK main loops), keeping idle memory delta under 10 MiB. Exposes live assistant state (`AppState`), Push-to-Talk, Always Listen toggle, Dashboard launcher, Pause, and Quit actions. Decouples system shutdown by receiving an injected asynchronous shutdown callback rather than a concrete lifecycle manager dependency. Integrates with `StateEventBus` for bounded non-blocking state change dispatch.

## 13. Exact Algorithms / Security Invariants
### State Event Bus
```python
class StateEventBus:
    def __init__(self) -> None:
        self._subscriptions: dict[str, asyncio.Queue[AppState]] = {}

    def subscribe(self) -> StateSubscription:
        if len(self._subscriptions) >= MAX_STATE_SUBSCRIBERS:
            raise StateSubscriberLimitError
        subscription_id = str(uuid.uuid4())
        queue: asyncio.Queue[AppState] = asyncio.Queue(maxsize=STATE_QUEUE_SIZE)
        self._subscriptions[subscription_id] = queue
        return StateSubscription(id=subscription_id, queue=queue)

    def unsubscribe(self, subscription_id: str) -> None:
        self._subscriptions.pop(subscription_id, None)

    def publish(self, state: AppState) -> None:
        snapshot = state.model_copy(deep=True)
        for queue in tuple(self._subscriptions.values()):
            if queue.full():
                try:
                    queue.get_nowait()
                except asyncio.QueueEmpty:
                    pass
            try:
                queue.put_nowait(snapshot)
            except asyncio.QueueFull:
                pass
```
No blocking callback runs inside state mutation. The tray updates D-Bus presentation asynchronously from its queue.

## 14. Reference Implementation / Capsule Guidance
Uses FreeDesktop StatusNotifierItem D-Bus protocol specification via standard asyncio D-Bus connection.

## 15. Concurrency Model
Async D-Bus message handling on system/session bus; state updates dispatched asynchronously without blocking caller.

## 16. Cancellation Behavior
Tray cancellation unregisters SNI service path from D-Bus and releases bus name ownership cleanly.

## 17. Timeout Behavior
D-Bus method call timeout bounded to 2.0 seconds.

## 18. Retry / Idempotency Behavior
State change updates are idempotent; re-sending identical `AppState` does not generate redundant D-Bus signals.

## 19. Error Behavior
D-Bus daemon disconnection triggers auto-reconnect backoff without terminating main daemon.

## 20. Security Invariants
D-Bus interface exposes only preapproved menu actions (Toggle Mute, Show Dashboard, Quit); zero arbitrary execution.

## 21. Resource Limits
Icon pixmap cache bounded to 4 standard state icons. Event queue capped at 4 items per subscriber; max 32 subscribers.

## 22. Secrets / Privacy Behavior
No private conversation content, user tokens, or transcribed text exposed over D-Bus interface.

## 23. Failure Cases / Edge Cases
- D-Bus daemon unavailable: Tray enters degraded headless mode without crashing daemon.
- Subscriber queue full: Event bus drops oldest state projection, enqueuing latest snapshot without backpressure deadlocks.
- Subscriber limit exceeded: Raises `StateSubscriberLimitError` if more than 32 clients subscribe.
- Quit menu action triggered: Awaits injected shutdown callable, initiating clean application termination.
