## 12. Internal Schemas
PH180 executes verification across all 10 mandatory acceptance pillars:
1. **Full Unit/Integration:** Complete test suite passes cleanly with zero skips or failures.
2. **Permission Red-Team:** Adversarial attacks (path traversal, symlink swap, command injection, unapproved grant replay, secret extraction) fail closed.
3. **Browser Allowlist:** Unlisted domains, mismatched origins, and credential field extractions are blocked.
4. **Voice Privacy:** Zero network packets transmitted during continuous wake listening; audio segment strictly begins post-wake.
5. **Memory Stress:** Resident daemon remains under `MemoryHigh=240M` and `MemoryMax=300M` across 100 sustained command cycles.
6. **Clean Install:** `install.sh` installs the Python package, user systemd unit, and native messaging host cleanly.
7. **Restart/Login Autostart:** `systemctl --user enable project-hd` successfully autostarts daemon on user login.
8. **Offline Determinism:** Commands enter through `CommandRouter.route()`. For matched deterministic actions, `dispatcher.dispatch_match()` executes without making ANY network socket or HTTP attempts (`provider_call_count == 0`).
9. **Packaging & Native Host:** Extension manifest, native host manifest, and console script `project-hd` verify syntax and path schemas.
10. **Target-Ubuntu Manual Evidence:** Manual smoke checklist on target Ubuntu desktop (system tray icon, popup dialog, audio capture, browser control).
