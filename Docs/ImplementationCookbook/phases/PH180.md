## 13. Exact Algorithms

### Algorithm: Offline Determinism Proof
1. Initialize test environment with outbound network blocked (or invalid `NVIDIA_API_KEY="invalid-key"`).
2. Start Maya daemon instance.
3. Issue deterministic local commands:
   - "open terminal"
   - "git status"
   - "list files in ~/Projects"
   - "show time"
4. Verify:
   a. CommandRouter matches Tier 1 or Tier 2.
   b. ActionDispatcher executes corresponding executor.
   c. **Zero outbound network calls attempted.**
   d. Operation succeeds with `success=True`.
5. Issue an ambiguous prompt requiring reasoning:
   a. CommandRouter attempts Tier 4.
   b. Provider catches connection error gracefully.
   c. Returns "AI reasoning is temporarily offline; deterministic local commands remain active."
   d. Daemon does not crash, hang, or leak resources.

## 14. Reference Implementation
```python
# tests/test_offline_determinism.py
import pytest
from app.actions.schema import ActionRequest

@pytest.mark.anyio
async def test_offline_deterministic_actions_succeed(offline_daemon):
    # Proves deterministic actions work without network
    req = ActionRequest(action_id="core.open_terminal", arguments={})
    res = await offline_daemon.dispatcher.dispatch_action_request(req)
    assert res.success is True
```
