## 13. Exact Algorithms / Security Invariants
### Cgroup v2 Reader & Process Accounting
```python
from pathlib import Path

CGROUP_ROOT = Path("/sys/fs/cgroup")

def current_cgroup_v2_path() -> Path | None:
    for line in Path("/proc/self/cgroup").read_text().splitlines():
        parts = line.split(":", 2)
        if len(parts) == 3 and parts[0] == "0":
            return CGROUP_ROOT / parts[2].lstrip("/")
    return None

def read_cgroup_memory_bytes() -> tuple[int, int | None]:
    path = current_cgroup_v2_path()
    if path is None:
        raise CgroupUnavailableError
    current = int((path / "memory.current").read_text().strip())
    peak_path = path / "memory.peak"
    peak = int(peak_path.read_text().strip()) if peak_path.exists() else None
    return current, peak
```

### Application Memory Thresholds
- `MemoryHigh=240M`: Pressure threshold. Background tasks are paused, optional caches compacted, and a warning emitted.
- `MemoryMax=300M`: Systemd cgroup hard ceiling. The application does not rely on `gc.collect()` to recover from crossing `MemoryMax`.
- External user-approved tools (e.g. VS Code, browser) run in separate transient execution slices or tracked subprocess groups.

## 14. Reference Implementation / Capsule Guidance
Implements `LifecycleManager.monitor_memory` using Linux cgroups v2 (`memory.current`, `memory.peak`) with fallback to process tree summation.

## 15. Concurrency Model

## 16. Cancellation Behavior

## 17. Timeout Behavior
Memory sampling completes in < 5 milliseconds.

## 18. Retry / Idempotency Behavior
Monitoring is idempotent read-only telemetry; does not mutate system state under normal bounds.

## 19. Error Behavior
Missing cgroup controllers degrade gracefully to process RSS measurement without crashing.

## 20. Security Invariants
Process memory hard cap 300 MiB enforced via systemd cgroup `MemoryMax=300M` kernel enforcement.

## 21. Resource Limits
Soft memory pressure threshold: 240 MiB; hard ceiling: 300 MiB.

## 22. Secrets / Privacy Behavior
Memory metrics contain numeric byte counts only; zero user data or buffer contents in telemetry.

## 23. Failure Cases / Edge Cases
- Memory exceeds 240 MiB: `monitor_memory` flags `WARNING`; daemon pauses background tasks and triggers cache compaction.
- Memory approaches 300 MiB: Kernel cgroup enforces `MemoryMax`; daemon logs fatal boundary if signal received.
- `/sys/fs/cgroup` unmounted or v1 only: Falls back gracefully to `/proc/self/statm` without crashing.
