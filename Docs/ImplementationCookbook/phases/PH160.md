## 13. Exact Algorithms

### Algorithm: Full Stress Test Scenario
1. Start resident daemon with all background listeners active:
   - Always-listen voice pipeline continuously processing audio frames.
   - FastAPI dashboard serving active SSE client stream.
   - Firefox native messaging bridge connected.
   - Dispatch active streaming completion request through `NvidiaProvider`.
   - Dispatch active logical agent task running multi-step tool calls.
   - Concurrently write 100 audit events to SQLite database.
2. Sample memory every 100ms via `/proc/self/status` (`VmRSS`) and `resource.getrusage(resource.RUSAGE_SELF).ru_maxrss`.
3. Verify peak resident memory:
   - If `peak_rss_mb > 240.0`: log `WARNING` (approaching MemoryHigh).
   - If `peak_rss_mb > 300.0`: fail test with `MemoryLimitExceededError`.
4. Separate external process RSS (Firefox browser, child processes) from resident daemon cgroup.

## 14. Reference Implementation
```python
# app/core/lifecycle.py
import resource
import os

class LifecycleManager:
    @staticmethod
    def monitor_memory() -> MemorySnapshot:
        # ru_maxrss is in KB on Linux
        peak_kb = resource.getrusage(resource.RUSAGE_SELF).ru_maxrss
        peak_mb = peak_kb / 1024.0
        
        # Read current VmRSS from /proc/self/status
        current_mb = 0.0
        try:
            with open("/proc/self/status", "r", encoding="utf-8") as f:
                for line in f:
                    if line.startswith("VmRSS:"):
                        current_mb = float(line.split()[1]) / 1024.0
                        break
        except Exception:
            current_mb = peak_mb

        status = "OK"
        if peak_mb >= 300.0:
            status = "EXCEEDED"
        elif peak_mb >= 240.0:
            status = "WARNING"

        return MemorySnapshot(current_rss_mb=current_mb, peak_rss_mb=peak_mb, limit_mb=300.0, status=status)
```
