# Phase Packet: PH-110 — Firefox WebExtension & Native Messaging Host

## 1. Purpose
Implement the secure browser automation bridge between Maya's resident daemon and Mozilla Firefox via standard WebExtension Native Messaging. Features length-prefixed framing (max 1 MB), double permission gating (daemon domain allowlist + Firefox host permission), content script origin verification immediately prior to tab actions, and strict exclusion of password fields and credentials from DOM extraction.

## 13. Exact Algorithms

### Algorithm: Length-Prefixed Message Framing
1. Read exactly 4 bytes from stdin: `raw_length = await reader.readexactly(4)`.
2. Unpack unsigned 32-bit int: `length = struct.unpack("=I", raw_length)[0]`.
3. If `length > 1,048,576` (1 MB): raise `ValueError("Message size exceeds 1MB limit")`.
4. Read payload: `payload_bytes = await reader.readexactly(length)`.
5. Parse UTF-8 JSON.

### Algorithm: Double Permission & Origin Verification
1. **Daemon Side:**
   - Parse `target_url` extracting domain.
   - Verify domain against `config.browser.allowed_domains`. If not found, reject with `DomainNotAllowedError`.
2. **Browser Extension Side (`verifyTabOrigin` in `native.js`):**
   - Query `tab = await browser.tabs.get(tab_id)`.
   - Verify `new URL(tab.url).origin === expected_origin`.
   - If mismatch (e.g. tab navigated away): abort action, return error.
3. **Sensitive Field Exclusion (`generic.js`):**
   - Query DOM elements. Exclude elements matching `input[type='password']`, `[autocomplete*='password']`, `[data-secret]`.
   - Never extract cookies or local storage tokens.

## 15. Concurrency Model
- Async multiplexing over stdin/stdout pipes using correlation IDs for concurrent tab requests.

## 16. Cancellation Behavior
- Cancelling a browser command sends an abort signal to the content script, releasing the pending future.

## 17. Timeout Behavior
- 15.0s timeout per browser command. Fails closed with `BrowserCommandTimeoutError`.

## 18. Retry/Idempotency Behavior
- `READ` operations may retry once if tab is still loading.
- `CLICK`, `TYPE`, `SUBMIT` actions are non-idempotent and are never auto-retried.

## 19. Error Behavior
- Pipe disconnected: Sets bridge status to `DISCONNECTED`, raises `BrowserBridgeDisconnectedError`.
- Tab closed: Raises `TabNotFoundError`.

## 20. Security Invariants
- **Primary Enforcement:** Domain allowlist in Python daemon + origin check in content script.
- **Defense in Depth:** Passwords and credentials filtered from DOM serialization.
- **Fail-Closed:** Origin mismatch or unlisted domain strictly rejects command.

## 21. Resource Limits
- Max native message size: 1 MB.
- Max DOM extraction text: 100,000 characters (~100 KB).

## 22. Secrets/Privacy Behavior
- Password fields, session tokens, and auth cookies are excluded from extraction.

## 23. Failure Cases
- Firefox process killed: Native messaging pipe closes with EOF; daemon gracefully resets connection.
- Target webpage changes origin during action: Origin check blocks execution.
