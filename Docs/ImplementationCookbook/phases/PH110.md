# Phase Packet: PH110 — Firefox WebExtension & Native Messaging Host

## 1. Purpose
Implement the multi-tier browser automation bridge separating the resident daemon, transient native host executable, and Firefox WebExtension. The daemon exposes an authenticated Unix Domain Socket (UDS) under `XDG_RUNTIME_DIR` (mode `0600`) with `SO_PEERCRED` UID verification and HMAC challenge-response handshake. The transient native messaging host is spawned by Firefox (`browser.runtime.connectNative`), bridges stdin/stdout to the daemon UDS with 4-byte native framing, and forwards only typed bounded messages. Every command enforces a strict 4-fold check (daemon domain policy from `config.browser.domains` + domain capability + Firefox permission + origin recheck) with sensitive element restriction.

### Domain Policy Matching
```python
def find_domain_policy(browser_config: BrowserConfig, host: str) -> BrowserDomainConfig | None:
    normalized = host.rstrip(".").lower()
    for rule in browser_config.domains:
        if not rule.enabled:
            continue
        if domain_pattern_matches(rule.pattern, normalized):
            return rule
    return None
```

### 4-Fold Permission Gating
Every browser action must pass:
1. **Daemon Domain Policy:** Sourced from `config.browser.domains`.
2. **Exact Domain Capability:** Action type permitted for domain (e.g. read vs click).
3. **Firefox Extension Host Permission:** Declared in `manifest.json`.
4. **Immediate Current-Origin Recheck:** Content script verifies `window.location.origin` immediately prior to DOM query or execution.
5. **Sensitive Element Restriction:** Password inputs, hidden auth tokens, and session cookies are hard-blocked from read or type actions.

## 13. Exact Algorithms / Security Invariants
### UDS Handshake Protocol
1. Daemon binds `$XDG_RUNTIME_DIR/project-h/browser.sock` (mode 0600) and writes secret to `native-host.secret` (mode 0600).
2. Native host connects over UDS; daemon verifies client UID matches current process UID via `SO_PEERCRED`.
3. Daemon generates random 32-byte challenge; native host reads secret and returns HMAC-SHA256 signature.
4. Daemon verifies HMAC using constant-time comparison and issues transient session ID.
5. Each command carries session ID and request sequence number; replayed or out-of-order packets are rejected.

## 15. Concurrency Model
Asyncio UDS server in daemon; separate native-host process reads stdin and writes stdout via async pipes.

## 16. Cancellation Behavior
Closing browser extension terminates native-host process; UDS socket connection closed and client session cleaned up.

## 17. Timeout Behavior
Command round-trip timeout bounded to 5.0 seconds.

## 18. Retry / Idempotency Behavior
Browser commands carry unique request IDs; duplicate responses discarded by request tracker.

## 19. Error Behavior
Socket disconnect or framing error resets protocol state and triggers re-handshake on next command.

## 20. Security Invariants
Authenticated UDS bound to mode 0700 runtime directory, 0600 socket file, with `SO_PEERCRED` UID verification.

## 21. Resource Limits
Maximum message size strictly enforced at 1,048,576 bytes (1 MiB Project H limit) in both directions.

## 22. Secrets / Privacy Behavior
DOM content extracted exclusively from allowlisted domain patterns defined in `config.browser.domains`. Password inputs and session cookies are excluded from extraction.

## 23. Failure Cases / Edge Cases
- Client UID mismatch: `SO_PEERCRED` check fails; connection dropped immediately without processing.
- Unlisted domain requested: Host does not match any rule in `config.browser.domains`; returns `BrowserDomainDeniedError`.
- Message size exceeds 1 MiB: Framing reader aborts and closes socket with `NativeBridgePayloadTooLargeError`.
- Password field interaction: Target element has `type="password"`; blocked with `SensitiveElementBlockedError`.
