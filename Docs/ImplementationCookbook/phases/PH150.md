## 1. Purpose
Implement developer workflows for Maya: repository registration, Git status and diff inspection, test command execution under policy, and launching workspaces in VS Code. Introduces the `DeveloperWorkflowService` in `app/developer/workflow.py` positioned **above the central ActionDispatcher**, guaranteeing that developer tooling never bypasses policy or directly invokes executors with raw argv. Enforces that code edits require an inspection and verification loop, that **auto-commit is strictly disabled by default**, and that `RegistryMatch` is never manually fabricated.

## 12. Internal Schemas
```
DeveloperWorkflowService
  │
  ├── Git / Test Subprocess Step:
  │     ActionRequest(tool="process.run", arguments={"argv": ["git", "status"], "cwd": repo_path})
  │     └──> dispatcher.dispatch_request() ──> PolicyEngine ──> ProcessExecutor
  │
  ├── File Read / Write Step:
  │     ActionRequest(tool="file.read" / "file.write", arguments={"path": ...})
  │     └──> dispatcher.dispatch_request() ──> PolicyEngine ──> FileExecutor
  │
  └── Deterministic Action Step:
        outcome = registry.resolve(command_text)
        └──> dispatcher.dispatch_match(outcome) ──> ActionDispatcher
```

### Safety Invariants
1. **NEVER DIRECTLY INVOKE EXECUTORS:** The developer service never calls `ProcessExecutor.execute(argv, ...)` directly.
2. **NEVER FABRICATE REGISTRYMATCH:** Only `ActionRegistry.resolve()` produces trusted matches. Never construct `RegistryMatch(...)` directly.
3. **USE CONFIG.FILES.ROOTS:** Allowed workspace roots are validated against `config.files.roots`. There is no nonexistent `config.security.allowed_roots`.
4. **AUTO-COMMIT DISABLED BY DEFAULT:** Auto-commit is disabled by default; committing requires explicit verification and user confirmation.

## 13. Exact Algorithms / Security Invariants
### Developer Workflow Service API
```python
class DeveloperWorkflowService:
    def __init__(self, dispatcher: ActionDispatcher, registry: ActionRegistry, config: Config) -> None:
        self._dispatcher = dispatcher
        self._registry = registry
        self._config = config

    async def run_process_step(self, *, argv: list[str], cwd: Path, reason: str) -> ActionResult:
        request = ActionRequest(
            id="developer.process",
            tool="process.run",
            arguments={"argv": argv, "cwd": str(cwd), "env": {}},
            reason=reason,
            workspace=str(cwd),
        )
        return await self._dispatcher.dispatch_request(request)

    async def run_registered_command(self, command_text: str) -> ActionResult:
        outcome = self._registry.resolve(command_text)
        if isinstance(outcome, RegistryMatch):
            return await self._dispatcher.dispatch_match(outcome)
        if isinstance(outcome, RegistryAmbiguity):
            return ActionResult(success=False, error="Ambiguous deterministic command")
        return ActionResult(success=False, error="No deterministic action matched")
```

## 14. Reference Implementation / Capsule Guidance

## 15. Concurrency Model
Async workflow execution; individual steps executed sequentially under task cancellation monitor.

## 16. Cancellation Behavior
Cancelling workflow execution immediately terminates running child process via executor contract.

## 17. Timeout Behavior
Default workflow timeout 300 seconds; step timeout 60 seconds.

## 18. Retry / Idempotency Behavior
Workflow read actions are idempotent; mutating actions (e.g. git commit) require explicit preapproval.

## 19. Error Behavior
Step failure halts workflow execution immediately and returns structured `ActionResult` with failure details.

## 20. Security Invariants
Workflows execute strictly via `ActionDispatcher`; direct unmanaged subprocess invocation is forbidden.

## 21. Resource Limits
Process output bounded by standard 10 MiB limit; workflow history bounded to 50 items.

## 22. Secrets / Privacy Behavior
Git credentials, SSH keys, and commit signatures handled by ambient OS tools without caching in memory.

## 23. Failure Cases / Edge Cases
- Target path outside `config.files.roots`: Rejected immediately with `UnauthorizedWorkspaceRootError`.
- Git process fails: Subprocess non-zero return code captured; halts workflow and returns failure result.
- Output exceeds 10 MiB: Output stream truncated with warning marker.
- Ambiguous phrase provided: Returns failure result requiring clarification.
