## 13. Exact Algorithms

### Algorithm: Developer Workflow Execution
1. Validate `repo_path` is resolved, exists, and is within `config.security.allowed_roots`.
2. Check `.git` directory exists.
3. For step `git_status`:
   - Run `['git', 'status', '--porcelain']` via `ProcessExecutor`.
   - Parse porcelain output into `modified_files` and `untracked_files`.
4. For step `git_diff`:
   - Run `['git', 'diff']` bounded to 100 KB output.
5. For step `test`:
   - Run test command (e.g. `['pytest', '-v']`) under process executor with 60s timeout.
6. For step `commit`:
   - **Auto-commit is strictly forbidden by default.**
   - If requested, route through PolicyEngine as `RiskLevel.HIGH`, requiring human confirmation via `ApprovalBroker`.

## 14. Reference Implementation
```python
class DeveloperToolExecutor:
    def __init__(self, process_executor: ProcessExecutor):
        self.process_executor = process_executor

    async def git_status(self, repo_path: Path) -> GitStatusResult:
        code, out, _ = await self.process_executor.execute(["git", "status", "--porcelain", "-b"], cwd=repo_path)
        lines = out.strip().splitlines()
        branch = lines[0].replace("## ", "") if lines else "unknown"
        modified = [l[3:] for l in lines[1:] if not l.startswith("??")]
        untracked = [l[3:] for l in lines[1:] if l.startswith("??")]
        return GitStatusResult(branch=branch, is_clean=len(lines) <= 1, modified_files=modified, untracked_files=untracked)
```

## 15. Concurrency Model
- Git operations serialized per repository to avoid index lock collisions.

## 16. Cancellation Behavior
- Cancelling test or git operations immediately issues `SIGTERM` to child process.

## 17. Timeout Behavior
- Git commands timeout after 10.0s. Test commands timeout after 120.0s.

## 18. Retry/Idempotency Behavior
- `git status` and `git diff` are read-only and idempotent.
- Edit and commit operations are non-idempotent.

## 19. Error Behavior
- Git command failure: returns structured `exit_code` and `stderr` without raising uncaught exception.

## 20. Security Invariants
- **Primary Enforcement:** Commands execute strictly via `ProcessExecutor` argv arrays; `shell=True` is forbidden.
- **Root Containment:** Repositories must reside within declared allowed roots (e.g. `~/Projects`).
- **No Auto-Commit:** Model cannot autonomously commit or push code.

## 21. Resource Limits
- Diff output capture capped at 100 KB.
- Test log output capped at 64 KB.

## 22. Secrets/Privacy Behavior
