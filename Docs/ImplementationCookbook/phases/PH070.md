# Phase Packet: PH-070 — Command Router & Single-Agent Runtime

## 1. Purpose
Implement the 4-tier `CommandRouter` and bounded single-task `AgentRuntime`. The router guarantees exact deterministic local actions execute with zero external AI calls, while ambiguous tasks route to Nemotron. The agent runtime executes multi-step task loops bounded by strict step (max 15) and API call budgets (max 20), routing every tool proposal through `ActionDispatcher`.

## 13. Exact Algorithms

### Algorithm: 4-Tier Command Router
1. Input check: trim `command_text`. If empty, reject with `EmptyCommandError`.
2. **Tier 1 (Exact Match):** Query `ActionRegistry.find_exact_match(command_text)`. If match found, return `CommandRoutingDecision(mode="EXACT_MATCH", action_request=match.to_request())`. **Zero AI calls made.**
3. **Tier 2 (Built-in Capabilities):** Check system commands (e.g. `open app <name>`, `open url <url>`). If matched, construct deterministic `ActionRequest`.
4. **Tier 3 (Structured Regex):** Evaluate local slot patterns. If unambiguous slot values extracted, return deterministic request.
5. **Tier 4 (AI Reasoning):** If all local matches fail or confidence < 0.90, route prompt to `NvidiaProvider` or dispatch `AgentRuntime`.

### Algorithm: Agent Step Loop
1. Acquire single active agent lock (`asyncio.Lock`). If already busy, raise `AgentBusyError`.
2. Initialize `step = 0`, `transcript = []`.
3. Loop while `step < task.max_steps`:
   a. Send transcript and tool schemas to `NvidiaProvider.complete()`.
   b. If model returns final content without tool calls: task completed, break.
   c. If model returns tool calls:
      i. For each tool call, validate arguments via strict Pydantic parsing.
      ii. Dispatch tool via `ActionDispatcher.dispatch_action_request()`.
      iii. Append tool result to transcript.
   d. Increment `step += 1`.
4. If `step >= task.max_steps`, set `error="AgentStepLimitExceeded"`.
5. Release active agent lock, return `AgentTaskResult`.

## 14. Reference Implementation
```python
class CommandRouter:
    def __init__(self, registry: ActionRegistry, provider: NvidiaProvider, dispatcher: ActionDispatcher):
        self.registry = registry
        self.provider = provider
        self.dispatcher = dispatcher

    async def route(self, text: str, source: str) -> CommandRoutingDecision:
        match = self.registry.find_match(text)
        if match and match.confidence >= 1.0:
            return CommandRoutingDecision(mode="EXACT_MATCH", action_request=match.to_request())
        # AI reasoning fallback
        return CommandRoutingDecision(mode="AI_REASONING")
```

## 15. Concurrency Model
- Router operations are stateless and concurrent.
- `AgentRuntime` enforces strict single-concurrency via `asyncio.Lock`. Only one active task runs at any time.

## 16. Cancellation Behavior
- `cancel_task` interrupts the active step loop, kills running subprocesses, and marks task `CANCELLED`.

## 17. Timeout Behavior
- Each agent step has a 30s timeout. Whole task capped at 300s total runtime.

## 18. Retry/Idempotency Behavior
- Exact matches are executed once.
- Agent tool calls follow standard dispatcher non-idempotent rules (never auto-retried on failure).

## 19. Error Behavior
- Router ambiguity: Returns `RoutingAmbiguityError`, asks user for clarification instead of guessing.
- Agent budget exhausted: Halts execution immediately, returns partial evidence to user.

## 20. Security Invariants
- **Primary Enforcement:** Agent CANNOT execute tools directly; every step calls `ActionDispatcher.dispatch_action_request()`.
- **Policy Check:** Tool calls proposed by the AI go through the exact same PolicyEngine checks as user commands.
- **No Self-Escalation:** Agent cannot broaden its own permissions, add preapprovals, or spawn unlimited peer agents.

## 21. Resource Limits
- Max 15 steps per task.
- Max 20 external AI API calls per task.
- Transcript buffer capped at 64 KB.

## 22. Secrets/Privacy Behavior
- Transcripts held in memory during execution; sensitive credentials redacted before archiving.

## 23. Failure Cases
- Model produces infinite tool calling loop: Cut off at step 15 by `max_steps` cap.
- Subprocess hangs during agent step: Terminated cleanly by process executor timeout.
