# Phase Packet: PH070 — Command Router & Single-Agent Runtime

## 1. Purpose
Implement the 4-tier `CommandRouter` and bounded single-task `AgentRuntime`. The router guarantees exact deterministic local actions execute with zero external AI calls by resolving against `ActionRegistry` and dispatching via `dispatcher.dispatch_match(outcome)`. Ambiguous commands return `RouteMode.AMBIGUOUS` requiring user clarification. Complex requests route to `AIProvider` reasoning proposals dispatched via `dispatcher.dispatch_request(request)`. The agent runtime executes multi-step task loops bounded by strict step (max 30) and API call budgets (max 20), routing every tool proposal through `ActionDispatcher`, and requiring explicit verification by an `AgentVerifier` before declaring completion.

## 12. Internal Schemas
```python
from enum import Enum
from typing import Protocol
from pydantic import BaseModel, ConfigDict, Field
from app.actions.schema import ActionResult

class RouteMode(str, Enum):
    EXACT_MATCH = "EXACT_MATCH"
    AMBIGUOUS = "AMBIGUOUS"
    BUILTIN = "BUILTIN"
    STRUCTURED = "STRUCTURED"
    AI_REASONING = "AI_REASONING"

class CommandRoutingResult(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    mode: RouteMode
    action_result: ActionResult | None = None
    response_text: str | None = None
    ambiguity_action_ids: tuple[str, ...] = ()

class AgentTask(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    task_id: str
    objective: str
    workspace_root: str
    max_steps: int = Field(default=15, le=30)
    max_budget_calls: int = Field(default=20, le=50)

class VerificationEvidence(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    check: str
    passed: bool
    summary: str

class VerificationResult(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    passed: bool
    evidence: tuple[VerificationEvidence, ...]

class AgentVerifier(Protocol):
    async def verify_task_completion(
        self,
        task: AgentTask,
        evidence: tuple[str, ...],
    ) -> VerificationResult: ...

class AgentTaskResult(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    task_id: str
    success: bool
    step_count: int
    api_calls_used: int
    evidence: list[str] = Field(default_factory=list)
    error: str | None = None
```

## 13. Exact Algorithms / Security Invariants
### Routing Precedence Order
```python
async def route(self, command_text: str, source: str) -> CommandRoutingResult:
    outcome = self.registry.resolve(command_text)
    if isinstance(outcome, RegistryMatch):
        result = await self.dispatcher.dispatch_match(outcome)
        return CommandRoutingResult(mode=RouteMode.EXACT_MATCH, action_result=result)
    if isinstance(outcome, RegistryAmbiguity):
        return CommandRoutingResult(
            mode=RouteMode.AMBIGUOUS,
            response_text="Command is ambiguous; clarification required.",
            ambiguity_action_ids=tuple(outcome.action_ids),
        )
    builtin = self.builtins.try_handle(command_text)
    if builtin is not None:
        return CommandRoutingResult(mode=RouteMode.BUILTIN, response_text=builtin)
    structured_request = self.structured_parser.try_parse(command_text, source=source)
    if structured_request is not None:
        result = await self.dispatcher.dispatch_request(structured_request)
        return CommandRoutingResult(mode=RouteMode.STRUCTURED, action_result=result)
    proposal = await self.ai_provider.propose_action(command_text)
    request = ActionRequest.model_validate(proposal)
    result = await self.dispatcher.dispatch_request(request)
    return CommandRoutingResult(mode=RouteMode.AI_REASONING, action_result=result)
```

### Trust Boundary Invariants
- `RegistryMatch` is dispatched strictly via `dispatcher.dispatch_match(outcome)`.
- `RegistryMatch` is **NEVER converted** to an `ActionRequest`.
- An `ActionRequest` from AI reasoning has **ZERO trusted registry provenance** and must undergo full policy evaluation via `dispatcher.dispatch_request(request)`.
- There is NO `find_exact_match()`, NO `find_match()`, NO `confidence` float, and NO `dispatch_action_request()`.

### Agent Verification Requirement
- `AgentVerifier.verify_task_completion(task, evidence)` executes automated acceptance checks.
- A task cannot conclude with `success=True` solely because the language model emitted a completion statement.

## 14. Reference Implementation / Capsule Guidance
Follows deterministic router architecture: Tier 1 registry matching precedes Tier 3/4 LLM agent execution. Never convert `RegistryMatch` into `ActionRequest`.

## 15. Concurrency Model
Async execution loop for agent step traversal; background tool calls dispatched asynchronously via `ActionDispatcher`. Single active agent lock prevents parallel agent tasks.

## 16. Cancellation Behavior
Agent execution tasks listen for cancellation tokens; gracefully abort active tool execution on `asyncio.CancelledError`.

## 17. Timeout Behavior
Default agent task timeout is 30 minutes; individual step timeout is 60 seconds; router timeout is 125 seconds.

## 18. Retry / Idempotency Behavior
Router resolution is deterministic and idempotent; agent workflows maintain step execution history.

## 19. Error Behavior
Step failures terminate task loop with failure result; errors recorded in `AgentTaskResult`.

## 20. Security Invariants
Agents execute actions exclusively through `ActionDispatcher`; direct executor invocation strictly prohibited.

## 21. Resource Limits
Maximum 1 active agent task; maximum 30 execution steps per task; maximum 20 tool calls per task. Transcript messages bounded to 100 entries / 1 MiB.

## 22. Secrets / Privacy Behavior
Agent workspace contained strictly within configured directory; tool arguments audited without logging secret values.

## 23. Failure Cases / Edge Cases
- Ambiguous phrase match: Returns `RouteMode.AMBIGUOUS` with candidate action IDs; does NOT guess or execute an action.
- Tool call argument schema violation: Fails step immediately; reports validation error to task loop.
- Step limit reached: Halts task loop at 30 steps with failure result; does not run runaway processes.
- API call limit reached: Halts model queries at 20 calls; terminates task with budget exhaustion.
- Concurrent agent launch: Second `run_task()` call fails immediately while a task is running.
