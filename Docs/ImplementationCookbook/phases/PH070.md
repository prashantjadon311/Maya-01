# Phase Packet: PH-070 — Command Router & Single-Agent Runtime

## 1. Purpose
Implement the 4-tier `CommandRouter` and bounded single-task `AgentRuntime`. The router guarantees exact deterministic local actions execute with zero external AI calls by resolving against `ActionRegistry` and dispatching via `dispatcher.dispatch_match(outcome)`. Ambiguous or high-level goals route to `AIProvider` reasoning proposals dispatched via `dispatcher.dispatch_request(request)`. The agent runtime executes multi-step task loops bounded by strict step (max 15) and API call budgets (max 20), routing every tool proposal through `ActionDispatcher`, and requiring explicit verification by an `AgentVerifier` before declaring completion.

```python
class CommandRoutingDecision(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    mode: Literal["EXACT_MATCH", "BUILTIN", "STRUCTURED", "AI_REASONING"]
    action_request: ActionRequest | None = None

class AgentTask(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    task_id: str
    objective: str
    workspace_root: str
    max_steps: int = Field(default=15, le=30)
    max_budget_calls: int = Field(default=20, le=50)

class AgentTaskResult(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    task_id: str
    success: bool
    step_count: int
    api_calls_used: int
    evidence: list[str] = Field(default_factory=list)
    error: str | None = None
```

## 13. Exact Routing & Trust Algorithms

### Routing Precedence Order
```python
outcome = registry.resolve(command_text)

if isinstance(outcome, RegistryMatch):
    # Tier 1: Deterministic local action match
    # CRITICAL: Preserve trusted snapshot-bound provenance
    return CommandRoutingDecision(mode="EXACT_MATCH")

if isinstance(outcome, RegistryAmbiguity):
    # Fail closed on ambiguity: prompt for clarification
    return CommandRoutingDecision(mode="STRUCTURED")

if is_builtin_command(command_text):
    # Tier 2: Built-in local command (status, quit, help)
    return CommandRoutingDecision(mode="BUILTIN")

# Tier 4: Fall back to AI reasoning proposal
return CommandRoutingDecision(mode="AI_REASONING")
```

### Trust Boundary Invariants
- `RegistryMatch` is dispatched strictly via `dispatcher.dispatch_match(outcome)`.
- `RegistryMatch` is **NEVER converted** to an `ActionRequest`.
- An `ActionRequest` from AI reasoning has **ZERO trusted registry provenance** and must undergo full policy evaluation via `dispatcher.dispatch_request(request)`.
- There is NO `find_exact_match()`, NO `find_match()`, NO `confidence` float, and NO `dispatch_action_request()`.

### Agent Verification Requirement
- `AgentVerifier.verify_task_completion(task, evidence)` executes automated acceptance checks (e.g. file existence, test pass, git status).
- A task cannot conclude with `success=True` solely because the language model emitted a completion statement.
