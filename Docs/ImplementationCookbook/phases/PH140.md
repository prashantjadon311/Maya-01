## 12. Internal Schemas
Every view specified in `Docs/UI.md` has an exact HTML markup container, active state controller, and test assertions:

1. **Home (`#view-home`):** Hero section, live status badge, quick actions card grid, recent activity feed.
2. **Chat (`#view-chat`):** Scrollable message stream, tool execution badges, final assistant responses only (zero raw reasoning disclosure), message composer with voice toggle.
3. **Tasks/Agents (`#view-tasks`):** Active task card, step-by-step progress list, tool invocation audit, step/budget consumption bars, abort button.
4. **Browser (`#view-browser`):** Firefox native bridge status indicator, domain allowlist table with toggles, recent web action history, credential masking notice.
5. **Voice (`#view-voice`):** Always-listen toggle, wake word sensitivity slider, live audio input level meter, silence timeout selector.
6. **Actions (`#view-actions`):** Deterministic action pack browser, phrase template search filter, pack reload trigger with diagnostic banner.
7. **Permissions (`#view-permissions`):** Preapproved rules table, path boundary list, interactive approval timeout configuration, pending approval indicators.
8. **Files/Workspaces (`#view-files`):** Allowed file roots table, canonical path containment indicator, read-only vs read-write badges, file size limits display.
9. **Developer (`#view-developer`):** Repository path selector, git status summary, test runner trigger, auto-commit toggle (default disabled), run log terminal viewer.
10. **Settings (`#view-settings`):** Full configuration editor bound to all sections of `Config` (`assistant`, `voice`, `stt`, `ai`, `dashboard`, `agents`, `resources`, `privacy`, `browser`, `files`), save/reset buttons.

## 14. Reference Implementation / Capsule Guidance
Single-page responsive dashboard interface utilizing offline Bootstrap 5.3 CSS and vanilla ES6 JavaScript.

## 15. Concurrency Model
Event-driven browser UI using native `EventSource` for real-time SSE stream consumption.

## 16. Cancellation Behavior
SSE connection closes automatically when dashboard tab is closed or navigated away.

## 17. Timeout Behavior
SSE reconnects with exponential backoff (1s, 2s, 5s) if connection is interrupted.

## 18. Retry / Idempotency Behavior
UI state renderers are idempotent projections of received `AppState` and audit events.

## 19. Error Behavior
Network disconnect displays offline indicator banner without throwing unhandled JavaScript errors.

## 20. Security Invariants
Zero external CDN dependencies; all stylesheets, fonts, and scripts hosted locally from `app/web/`. Hidden model reasoning traces (`<think>`) are never parsed or rendered.

## 21. Resource Limits
Dashboard DOM limited to max 500 audit log rows to prevent browser tab memory exhaustion.

## 22. Secrets / Privacy Behavior
Private thinking traces and chain-of-thought tokens are strictly excluded from display; only final assistant responses shown.

## 23. Failure Cases / Edge Cases
- Backend SSE disconnected: UI switches status pill to "Reconnecting", triggers backoff timer.
- Malformed SSE payload received: JSON parse error caught; logs diagnostic to console without breaking DOM render loop.
- User requests Voice Output: Tooltip explains TTS is disabled in V1 minimal desktop profile to preserve memory budget.
- Tab backgrounded: SVG animation timers paused, reducing idle browser CPU to 0%.
