# Phase Packet: PH-140 — Vanilla Web Dashboard Frontend

## 1. Purpose
Implement the Maya web dashboard interface using static HTML, local Bootstrap 5.3 CSS, custom CSS, vanilla JavaScript, and SVG AI Core animations. Operates without any Node.js runtime, build steps, or frontend frameworks (React, Vue, Vite). Features tabbed navigation, real-time SSE state updates, hidden-tab animation pausing, and reduced motion accessibility.

## 13. Exact Algorithms

### Algorithm: Dashboard Event Handling & SSE
1. Open `const evtSource = new EventSource('/api/v1/events')`.
2. On message:
   a. Parse JSON payload.
   b. If `type === 'STATE_CHANGE'`: update status badge and SVG AI Core pulse speed.
   c. If `type === 'AUDIT_EVENT'`: append row to Audit tab table.
3. On connection error: reconnect with exponential backoff (1s, 2s, 5s).

### Algorithm: Hidden Tab Animation Pausing
1. Listen to `document.addEventListener('visibilitychange', () => { ... })`.
2. If `document.hidden === true`:
   - Pause SVG CSS animations (set `animation-play-state: paused`).
3. If `document.hidden === false`:
   - Resume SVG CSS animations (set `animation-play-state: running`).

## 14. Reference Implementation
```javascript
// app/web/js/app.js
document.addEventListener('visibilitychange', () => {
  const core = document.getElementById('ai-core-svg');
  if (core) {
    core.style.animationPlayState = document.hidden ? 'paused' : 'running';
  }
});
```
