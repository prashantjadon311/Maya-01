## 12. Internal Schemas
Every view specified in `Docs/UI.md` has an exact HTML markup container, active state controller, and test assertions:

1. **Home (`#view-home`):** Hero section, live status badge, quick actions card grid, recent activity feed.
2. **Chat (`#view-chat`):** Scrollable message stream, tool execution badges, streaming thought disclosure, message composer with voice toggle.
3. **Tasks/Agents (`#view-tasks`):** Active task card, step-by-step progress list, tool invocation audit, step/budget consumption bars, abort button.
4. **Browser (`#view-browser`):** Firefox native bridge status indicator, domain allowlist table with toggles, recent web action history, credential masking notice.
5. **Voice (`#view-voice`):** Always-listen toggle, wake word sensitivity slider, live audio input level meter, silence timeout selector.
6. **Actions (`#view-actions`):** Deterministic action pack browser, phrase template search filter, pack reload trigger with diagnostic banner.
7. **Permissions (`#view-permissions`):** Preapproved rules table, path boundary list, interactive approval timeout configuration, pending approval indicators.
8. **Files/Workspaces (`#view-files`):** Allowed file roots table, canonical path containment indicator, read-only vs read-write badges, file size limits display.
9. **Developer (`#view-developer`):** Repository path selector, git status summary, test runner trigger, auto-commit toggle (default disabled), run log terminal viewer.
10. **Settings (`#view-settings`):** Full configuration editor bound to all sections of `Config` (`assistant`, `voice`, `stt`, `ai`, `dashboard`, `agents`, `resources`, `privacy`, `browser`, `files`), save/reset buttons.

### Persistent Structural Components
- **Top Bar:** System brand, status indicator, connection status (online/offline/reconnecting), global emergency pause button.
- **Sidebar Navigation:** Collapsible sidebar with icons and accessible labels for all 10 views, active tab highlighting.
- **Composer Bar:** Bottom sticky input with multi-line auto-expand, submit button, microphone trigger.

### AI Core Visual States (SVG Animations)
- States: `DISABLED` (grayed out), `READY_WAKE` (gentle pulse), `WAKE_DETECTED` (flash), `RECORDING` (expanding rings), `THINKING` (orbiting arcs), `EXECUTING` (steady glow), `ERROR` (amber alert pulse).

### Accessibility & Ergonomics
- **Responsive Breakpoints:** Desktop (`>=1200px`), Tablet (`768px - 1199px`), Mobile (`<768px` with drawer sidebar).
- **Reduced Motion:** `@media (prefers-reduced-motion: reduce)` disables SVG pulse/orbit loops.
- **Hidden Tab Resource Pausing:** `document.addEventListener("visibilitychange")` pauses SVG animation timers when tab is hidden, resuming on visible.
- **Keyboard Navigation:** Logical `tabindex`, visible `:focus-visible` outline rings, `Alt+1..9` quick view navigation shortcuts.
- **Loading, Empty & Error States:** Defined for each list and table component.
