# Phase Packet: PH-130 — Local Dashboard Backend & SQLite Storage

## 1. Purpose
Implement the local web dashboard backend using FastAPI and local SQLite storage. The server binds strictly to `127.0.0.1:8765` with same-origin validation and zero wildcard CORS. Provides transactional configuration CRUD, action pack management, Server-Sent Events (SSE) state streaming, and paginated audit log queries.

## 13. Exact Algorithms

### Algorithm: Localhost App Creation & CORS Lockdown
1. Instantiate `app = FastAPI(title="Project H Dashboard", openapi_url=None, docs_url=None)`.
2. Add CORS middleware:
   - `allow_origins = ["http://127.0.0.1:8765", "http://localhost:8765"]`.
   - `allow_credentials = True`.
   - **`allow_origins = ["*"]` is strictly forbidden.**
3. Add Host validation middleware: reject any request where `Host` header is not `127.0.0.1:8765` or `localhost:8765` (protects against DNS rebinding).
4. Mount static files directory `app/web` at root `/`.

### Algorithm: SQLite WAL Mode Initialization
1. Open database connection to `~/.local/share/project-h/maya.db`.
2. Execute `PRAGMA journal_mode=WAL;`.
3. Execute `PRAGMA synchronous=NORMAL;`.
4. Create `audit_log` table with indexes on `timestamp` and `request_id`.
5. Create `preferences` key-value table.

## 15. Concurrency Model
- FastAPI runs asynchronously via Uvicorn within daemon event loop.
- SQLite writes serialized under transaction lock or WAL mode.

## 16. Cancellation Behavior
- Dropped client HTTP requests cleanly cancel downstream database queries.

## 17. Timeout Behavior
- 30.0s timeout per API request.

## 18. Retry/Idempotency Behavior
- GET endpoints are idempotent.
- PUT `/api/v1/config` is idempotent (overwrites target section atomically).

## 19. Error Behavior
- Invalid config JSON returns HTTP 422 Unprocessable Entity.
- Unauthorized cross-origin request returns HTTP 403 Forbidden.

## 20. Security Invariants
- **Primary Enforcement:** Server bound to `127.0.0.1` (never `0.0.0.0`).
- **Defense in Depth:** Host header check + CORS restriction blocks malicious external websites from issuing requests via user's browser.

## 21. Resource Limits
- Request body size limited to 64 KB.
- SSE broadcast queues bounded to max 50 events per subscriber.
- Audit retention: max 10,000 events.

## 22. Secrets/Privacy Behavior
- API keys, credentials, and tokens are never returned in GET config or GET audit endpoints.

## 23. Failure Cases
- Disk full during audit write: Logs warning to stderr, drops non-critical audit event, prevents daemon crash.
