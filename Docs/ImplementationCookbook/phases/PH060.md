## 13. Exact Algorithms

### Algorithm: Streaming Chat & Tool Parsing
1. Validate `len(messages) <= 32`; truncate oldest user turns if context exceeds limit.
2. Initialize `stream = await client.chat.completions.create(model="nvidia/nemotron-3-ultra-550b-a55b", messages=messages, tools=tools, stream=True, stream_options={"include_usage": True})`.
3. Loop over incoming SSE chunks:
   a. Check for delta content: if present, filter out `<think>...</think>` regex patterns.
   b. Check for delta tool calls: accumulate index, name, and partial JSON arguments into `ToolCallAccumulator`.
   c. Yield `ChatChunk` with sanitized text and completed tool calls.
4. On stream termination, ensure underlying response is closed.

### Algorithm: Filter Reasoning
1. Match pattern `re.compile(r'<think>.*?</think>', re.DOTALL)`.
2. Substitute matched blocks with empty string before exposing content to callers or logging.

## 14. Reference Implementation
```python
class NvidiaProvider:
    def __init__(self, api_key: str, base_url: str = "https://integrate.api.nvidia.com/v1"):
        self.api_key = api_key
        self.base_url = base_url
        self._client = AsyncOpenAI(base_url=self.base_url, api_key=self.api_key, max_retries=0, timeout=30.0)

    async def aclose(self) -> None:
        await self._client.close()
```

## 15. Concurrency Model
- Supports concurrent completion requests up to connection pool limit (default 10).
- Explicit `async with asyncio.timeout(30.0)` wraps every network call.

## 16. Cancellation Behavior
- When cancelled, the generator in `stream_chat` exits, closing the httpx response stream immediately.

## 17. Timeout Behavior
- 30.0s hard timeout on completion requests. Fails closed with `ProviderTimeoutError`.

## 18. Retry/Idempotency Behavior
- `max_retries = 0` configured in SDK client.
- Transient connection drops may retry once after a 1.0s backoff.

## 19. Error Behavior
- HTTP 401/403: Raises `AuthenticationError`.
- HTTP 429: Raises `ProviderRateLimitError`.
- HTTP 500/503: Raises `ProviderAPIError`.
- All errors are caught and translated into `MayaBaseError` subclasses.

## 20. Security Invariants
- **Primary Enforcement:** API key read from environment `NVIDIA_API_KEY`; never hardcoded, never logged.
- **Defense in Depth:** Raw model thoughts and internal reasoning tokens stripped before return.

## 21. Resource Limits
- Request context bounded to max 32 messages (~128 KB text).
- Output completion tokens bounded to max 4096.

## 22. Secrets/Privacy Behavior
- API keys masked in all log outputs (`nvapi-****`).
- Request payloads exclude passwords and local filesystem paths.

## 23. Failure Cases
- Outbound internet offline: Throws `ProviderAPIError`, router falls back to deterministic local actions.
- Malformed tool arguments returned by model: Throws `ToolParsingError`, model instructed to retry.
