## 12. Internal Schemas
```python
# app/ai/schema.py
from typing import Any, Literal
from pydantic import BaseModel, ConfigDict, Field

class ChatMessage(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    role: Literal["system", "user", "assistant", "tool"]
    content: str
    name: str | None = None
    tool_call_id: str | None = None

class ToolDefinition(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    name: str = Field(min_length=1, max_length=128)
    description: str = Field(default="", max_length=1024)
    parameters: dict[str, Any] = Field(default_factory=dict)

class ToolCall(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    id: str
    name: str
    arguments: dict[str, Any]

class ChatChunk(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    content_delta: str = ""
    tool_calls: tuple[ToolCall, ...] = ()
    done: bool = False

class ChatResponse(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    content: str
    tool_calls: tuple[ToolCall, ...] = ()
```

`app/ai/base.py` defines the protocol:
```python
from collections.abc import AsyncIterator
from typing import Protocol
from app.ai.schema import ChatChunk, ChatMessage, ChatResponse, ToolDefinition

class AIProvider(Protocol):
    async def complete(
        self,
        messages: list[ChatMessage],
        tools: list[ToolDefinition] | None = None,
    ) -> ChatResponse: ...

    async def stream_chat(
        self,
        messages: list[ChatMessage],
        tools: list[ToolDefinition] | None = None,
    ) -> AsyncIterator[ChatChunk]: ...

    async def aclose(self) -> None: ...
```

## 13. Exact Algorithms / Security Invariants
### Stateful Reasoning Filter
The reasoning parser strips `<think>...</think>` internal model reasoning chunks. It maintains parsing state across stream chunks:
- State tracks: `_buffer: str` and `_inside_reasoning: bool`.
- Handles tags split across arbitrary chunk boundaries, such as `"<thi"` + `"nk>internal logic"` + `"</think>visible output"`.
- Uses suffix/prefix matching to preserve partial tag prefixes until the subsequent chunk resolves them.
- Fails closed on partial open tag at stream finish: partial tag prefix is discarded, preventing reasoning leakage.

### Single Reusable Client
```python
self._client = AsyncOpenAI(
    api_key=api_key,
    base_url=config.base_url,
    timeout=float(config.timeout_seconds),
    max_retries=0,
)
```
- Reuses client instance across daemon lifetime; closed cleanly via `aclose()`.
- Explicit `max_retries=0` prevents duplicate model execution or tool calling.

## 14. Reference Implementation / Capsule Guidance
`NvidiaProvider` adapts the OpenAI-compatible streaming API to typed `ChatChunk` and `ChatResponse`. Never import `ToolDefinition` from `app.actions.schema`.

## 15. Concurrency Model
Async HTTP transport managed via `openai.AsyncOpenAI` using connection pooling and async event loops.

## 16. Cancellation Behavior
Active HTTP streaming connections are cancelled cleanly by aborting the stream context manager on `asyncio.CancelledError`. Client resources are freed.

## 17. Timeout Behavior
Transport timeout governed by `config.ai.timeout_seconds` (default 120s); initial chunk response timeout is 15s.

## 18. Retry / Idempotency Behavior
Idempotent query completions; streaming calls can be aborted and re-queried without persistent side effects. Zero automatic SDK retries.

## 19. Error Behavior
Network drop, HTTP 4xx/5xx, or token limit errors raise typed `AIProviderError` subclasses; never bubble raw HTTP client exceptions.

## 20. Security Invariants
Zero API key leakage in logs or exceptions; authorization bearer header injected strictly during request construction. Raw internal model reasoning traces are never emitted.

## 21. Resource Limits
Input messages bounded to 32 items; output tokens capped at `config.ai.max_output_tokens` (8192 tokens); reasoning stream buffer bounded to 64 KiB.

## 22. Secrets / Privacy Behavior
API key loaded exclusively from environment variable configured in `config.ai.api_key_env`; never written to disk or logs.

## 23. Failure Cases / Edge Cases
- Missing API key: `os.environ.get(config.api_key_env)` returns None; raises `ProviderConfigurationError` before socket allocation.
- HTTP 401 Unauthorized / HTTP 429 Rate Limit: Wrapped into typed `AIProviderAuthError` / `AIProviderRateLimitError`.
- Network stream interrupted mid-turn: Cleans up stream generator and raises `AIProviderStreamError`.
- Split `<think>` tags across chunks: Handled statefully without leakage.
- Stream ends with unclosed `<think>` tag: Discards internal buffer, emitting only text prior to the unclosed tag.
