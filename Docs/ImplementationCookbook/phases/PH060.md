## 13. Exact Algorithms / Security Invariants
### Stateful Reasoning Filter
The reasoning parser strips `<think>...</think>` internal model reasoning chunks. It maintains parsing state across stream chunks:
- State tracks: `IN_NORMAL_TEXT`, `IN_OPENING_TAG`, `IN_THINKING`, `IN_CLOSING_TAG`.
- Handles tags split across arbitrary chunk boundaries, such as `"<thi"` + `"nk>internal logic"` + `"</think>visible output"`.
- Prevents reasoning text or partial tag fragments from leaking to consumers.

### Bounded Tool-Call Accumulation
- Accretion buffer indexed by tool call ID / index.
- Hard bound: Maximum 8 tool calls per turn; max 4096 bytes per tool argument payload.
- Only parses JSON when complete tool call finish reason is received; fails closed on malformed JSON.

### Retry Invariants
- `max_retries = 0` configured directly on `AsyncOpenAI(max_retries=0, timeout=config.ai.timeout_seconds)`.
- Never retry after streamed delta output or tool call observed.
- Never retry side-effecting operations.

## 14. Reference Implementation / Capsule Guidance
See `app/ai/base.py` and `app/ai/schema.py` for wire-neutral protocol models. Adapts external OpenAI-compatible streaming API to typed `ChatChunk` and `ChatResponse`.

## 15. Concurrency Model
Async HTTP transport managed via `httpx.AsyncClient` with bounded connection pool and connection limits.

## 16. Cancellation Behavior
Active HTTP streaming connections are cancelled cleanly by aborting the stream context manager on `asyncio.CancelledError`.

## 17. Timeout Behavior
Transport timeout governed by `config.ai.timeout_seconds` (default 120s); initial chunk response timeout is 15s.

## 18. Retry / Idempotency Behavior
Idempotent query completions; streaming calls can be aborted and re-queried without persistent side effects.

## 19. Error Behavior
Network drop, HTTP 4xx/5xx, or token limit errors raise typed `AIProviderError` subclasses; never bubble raw HTTP client exceptions.

## 20. Security Invariants
Zero API key leakage in logs or exceptions; authorization bearer header injected strictly during request construction.

## 21. Resource Limits
Input messages bounded to 32 items; output tokens capped at `config.ai.max_output_tokens` (8192 tokens); reasoning stream buffer bounded to 64 KiB.

## 22. Secrets / Privacy Behavior
API key loaded exclusively from environment variable configured in `config.ai.api_key_env`; never written to disk or logs.
