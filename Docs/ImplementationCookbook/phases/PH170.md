# Phase Packet: PH170 — Packaging & Systemd User Service Integration

## 1. Purpose
Package Maya for native Ubuntu Linux deployment as an installable user system. Freezes the console script entrypoints `project-hd = "app.main:main"` and `project-h-native-host = "app.browser.native_host:main"`, user package installation via dedicated virtual environment (`~/.local/share/project-h/venv`), user systemd service unit (`~/.config/systemd/user/project-hd.service`) enforcing `MemoryHigh=240M` and `MemoryMax=300M`, dynamic Firefox Native Messaging host manifest placement, safe environment variable loading for `NVIDIA_API_KEY` via `~/.config/project-h/environment`, and clean uninstaller / rollback procedures.

## 12. Internal Schemas
### Console Script Entrypoints
In `pyproject.toml`:
```toml
[project.scripts]
project-hd = "app.main:main"
project-h-native-host = "app.browser.native_host:main"
```

### Installation Layout
```text
~/.local/share/project-h/
    venv/
~/.config/project-h/
    environment (mode 0600)
~/.config/systemd/user/
    project-hd.service
~/.mozilla/native-messaging-hosts/
    project_h_firefox.json
```

### Systemd User Service (`project-hd.service`)
```ini
[Unit]
Description=Project H (Maya) Personal AI Assistant Daemon
After=network.target sound.target default.target

[Service]
Type=simple
ExecStart=%h/.local/share/project-h/venv/bin/project-hd
Restart=on-failure
RestartSec=3s
EnvironmentFile=-%h/.config/project-h/environment
MemoryHigh=240M
MemoryMax=300M

[Install]
WantedBy=default.target
```

### Dynamic Native Messaging Host Manifest Placement
`packaging/native-manifest/project_h_firefox.json.template`:
```json
{
  "name": "project_h_firefox",
  "description": "Project H Firefox Native Messaging Host",
  "path": "@NATIVE_HOST_PATH@",
  "type": "stdio",
  "allowed_extensions": [
    "project-h-extension@local"
  ]
}
```
`install.sh` resolves `@NATIVE_HOST_PATH@` to the exact resolved path `~/.local/share/project-h/venv/bin/project-h-native-host` dynamically at install time without hardcoding absolute user directory paths.

## 13. Exact Algorithms / Security Invariants
### Dedicated User Venv Installation Flow
```bash
python3 -m venv "${VENV_DIR}"
"${VENV_DIR}/bin/python" -m pip install --upgrade pip
"${VENV_DIR}/bin/pip" install "${PROJECT_ROOT}"
```
- Completely isolated from system Python and user global packages.
- Zero root or `sudo` requirements.
- Config directory `~/.config/project-h` created with permissions `0700`, `environment` file with `0600`.

## 14. Reference Implementation / Capsule Guidance
Provides systemd user service `project-hd.service` and installer scripts targeting Ubuntu 24.04+ LTS.

## 15. Concurrency Model
Installer executes sequentially in user session; service runs under user systemd manager.

## 16. Cancellation Behavior
Uninstall script cleanly stops systemd unit, removes user files, and deregisters Firefox native manifest.

## 17. Timeout Behavior
Service start timeout 30 seconds; watchdog interval 60 seconds.

## 18. Retry / Idempotency Behavior
Installer is idempotent; re-running `install.sh` upgrades existing installation safely.

## 19. Error Behavior
Missing prerequisites (Python 3.11+, Zenity, Firefox) halt install with clear remediation instructions.

## 20. Security Invariants
Zero root privilege escalation required; installs strictly to `~/.local/share/project-h/`.

## 21. Resource Limits
Installation disk footprint < 100 MiB including virtualenv dependencies.

## 22. Secrets / Privacy Behavior
Environment file created with permissions 0600 in directory mode 0700; zero secret leakage in logs.

## 23. Failure Cases / Edge Cases
- Missing Python 3.11+ venv module: Fails early with instruction to install `python3-venv`.
- Invalid file permissions on environment file: Service unit fails to load if permissions exceed 0600.
- Systemd user session unavailable: Installer warns user that lingering or user session bus is required.
- Uninstallation cleanup: Uninstaller disables systemd service, unlinks manifest, and removes venv without deleting user databases.

## 35. Forbidden Behavior
- DO NOT run systemd service as root; user services only (`systemctl --user`).
- DO NOT assume systemd inherits interactive shell secrets.
- DO NOT omit `MemoryHigh=240M` or `MemoryMax=300M` from unit file.
- DO NOT use `/home/USER/` placeholder in manifest template.

## 36. Stop Conditions
Stop if installer requires `sudo` or modifies system files outside user `$HOME`.
