## 12. Internal Schemas

```ini
# packaging/systemd/maya.service
[Unit]
Description=Project H (Maya) Personal Assistant Daemon
After=network.target sound.target

[Service]
Type=simple
ExecStart=%h/.local/bin/project-hd
Restart=on-failure
RestartSec=3s
MemoryHigh=240M
MemoryMax=300M
Slice=app-project_h.slice

[Install]
WantedBy=default.target
```

## 13. Exact Algorithms

### Algorithm: First-Run Installation
1. Create directories:
   - `~/.config/project-h/actions.d/`
   - `~/.local/share/project-h/`
   - `~/.config/systemd/user/`
   - `~/.mozilla/native-messaging-hosts/`
2. Install default `config.toml` if not already present.
3. Install `packaging/native-manifest/project_h_firefox.json` to `~/.mozilla/native-messaging-hosts/project_h_firefox.json`.
4. Install `packaging/systemd/maya.service` to `~/.config/systemd/user/maya.service`.
5. Run `systemctl --user daemon-reload`.
6. Run `systemctl --user enable --now maya.service`.

### Algorithm: Uninstallation
1. Run `systemctl --user disable --now maya.service`.
2. Remove `~/.config/systemd/user/maya.service`.
3. Remove `~/.mozilla/native-messaging-hosts/project_h_firefox.json`.
4. Run `systemctl --user daemon-reload`.

## 14. Reference Implementation
```bash
# packaging/install.sh
#!/usr/bin/env bash
set -euo pipefail

mkdir -p "$HOME/.config/project-h/actions.d"
mkdir -p "$HOME/.local/share/project-h"
mkdir -p "$HOME/.config/systemd/user"
mkdir -p "$HOME/.mozilla/native-messaging-hosts"

cp packaging/systemd/maya.service "$HOME/.config/systemd/user/maya.service"
cp packaging/native-manifest/project_h_firefox.json "$HOME/.mozilla/native-messaging-hosts/project_h_firefox.json"

systemctl --user daemon-reload
echo "Maya successfully installed to systemd user services."
```

## 15. Concurrency Model
- Managed by systemd process supervisor.

## 16. Cancellation Behavior
- `systemctl --user stop maya.service` issues SIGTERM; systemd escalates to SIGKILL if daemon fails to exit within 10s.

## 17. Timeout Behavior
- `TimeoutStopSec=10s` in systemd unit.

## 18. Retry/Idempotency Behavior
- Installation and uninstallation scripts are idempotent.

## 19. Error Behavior
- Service crash: systemd automatically restarts after 3 seconds (`Restart=on-failure`, `RestartSec=3s`).

## 20. Security Invariants
- **Primary Enforcement:** User service only; **never run as root**.
- **Resource Protection:** Kernel enforces `MemoryMax=300M` cgroup limit.

## 21. Resource Limits
- MemoryHigh: 240M
- MemoryMax: 300M

## 22. Secrets/Privacy Behavior
- Service unit references environment variables or `~/.config/project-h/config.toml`; secrets never stored in systemd unit.

## 23. Failure Cases
- Cgroup exceeded: Kernel terminates process with OOM; systemd restarts daemon with fresh memory state.
