## 12. Internal Schemas
### Console Script Entrypoint
In `pyproject.toml`:
```toml
[project.scripts]
project-hd = "app.main:main"
```
Executable installs to `~/.local/bin/project-hd`.

### Systemd User Service (`project-hd.service`)
```ini
[Unit]
Description=Project H (Maya) Personal AI Assistant Daemon
After=network.target sound.target default.target

[Service]
Type=simple
ExecStart=%h/.local/bin/project-hd
Restart=on-failure
RestartSec=3s
EnvironmentFile=-%h/.config/project-h/environment
MemoryHigh=240M
MemoryMax=300M

[Install]
WantedBy=default.target
```

### Safe Environment Variable Strategy
**Critical:** `systemd --user` units do NOT automatically inherit shell environment variables from interactive `.bashrc` or `.zshrc`. The service unit uses `EnvironmentFile=-%h/.config/project-h/environment` (mode `0600`). Users configure `NVIDIA_API_KEY` inside this secure file, or pass it via systemd credentials.

### Native Messaging Host Manifest (`project_h_firefox.json`)
```json
{
  "name": "project_h_firefox",
  "description": "Project H Firefox Native Messaging Host Bridge",
  "path": "/home/USER/.local/bin/project-h-native-host",
  "type": "stdio",
  "allowed_extensions": [
    "project-h-extension@local"
  ]
}
```
Placed in `~/.mozilla/native-messaging-hosts/project_h_firefox.json`.
