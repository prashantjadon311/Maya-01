# Phase Packet: PH120 — Specialized Browser Site Adapters

## 1. Purpose
Implement specialized semantic DOM content script adapters for supported sites: Google Search, Amazon, ChatGPT, Claude, Gemini, and Generic fallback. Adapters rely on resilient semantic selectors and accessibility roles. If site markup changes, adapters fail gracefully with `ADAPTER_OUTDATED` without crashing or escalating privileges. Testing proves real JavaScript adapter execution via Python Selenium with Firefox and geckodriver using local fixture pages under `tests/fixtures/browser/`, without requiring a Node.js runtime.

## 13. Exact Algorithms / Security Invariants
### Semantic Extraction Algorithm
```javascript
// extension/firefox/adapters/base.js
class BaseAdapter {
  extract(document) {
    throw new Error("Must implement extract()");
  }
  isApplicable(url) {
    throw new Error("Must implement isApplicable()");
  }
  sanitizeText(text) {
    if (!text) return "";
    return text.replace(/\s+/g, " ").trim();
  }
}
```
Adapters locate article containers, search result titles, and assistant response bubbles using ARIA roles (`role="main"`, `role="article"`) and data attributes. Sensitive input fields (`input[type="password"]`, `input[type="hidden"]`, session token elements) are strictly excluded from traversal.

## 14. Reference Implementation / Capsule Guidance

## 15. Concurrency Model
Event-driven JavaScript content script execution inside isolated WebExtension world.

## 16. Cancellation Behavior
Page navigation or tab closure immediately cancels in-flight extraction promises.

## 17. Timeout Behavior
DOM query timeout bounded to 3.0 seconds per extraction attempt.

## 18. Retry / Idempotency Behavior
DOM extraction operations are idempotent read-only queries with zero mutating page side effects.

## 19. Error Behavior
Selector changes on target websites fail gracefully with structured error code; never throw uncaught exceptions.

## 20. Security Invariants
Content scripts restricted to allowed domains; CSP headers respected; no external script injection.

## 21. Resource Limits
Extracted DOM text payload bounded to 512 KiB before dispatching to native host.

## 22. Secrets / Privacy Behavior
Password fields, hidden inputs, and payment details explicitly excluded from DOM extraction selectors.

## 23. Failure Cases / Edge Cases
- Website layout changed: Selectors fail to resolve primary nodes; adapter returns `{ status: "ADAPTER_OUTDATED", results: [] }`.
- Password / auth tokens present: Filter identifies sensitive input types and skips them.
- DOM size exceeds payload bound: Extraction halts at 512 KiB text ceiling with truncation marker.
- Tab navigated mid-extraction: Pending async promise rejects cleanly; error returned to native host.
