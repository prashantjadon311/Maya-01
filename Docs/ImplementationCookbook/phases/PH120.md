# Phase Packet: PH120 — Specialized Browser Site Adapters

## 1. Purpose
Implement specialized semantic DOM content script adapters for supported sites: Google Search, Amazon, ChatGPT, Claude, Gemini, and Generic fallback. Adapters rely on resilient semantic selectors and accessibility roles. If site markup changes, adapters fail gracefully with `ADAPTER_OUTDATED` without crashing or escalating privileges. Testing must prove real JavaScript adapter execution via Firefox test-profile or headless Firefox using local fixture pages, without requiring a Node.js runtime.

2. **GRACEFUL DEGRADATION:** If semantic selectors fail to find expected elements, returns `{ status: "ADAPTER_OUTDATED", results: [] }`. Fails closed with zero corruption.
3. **REAL JAVASCRIPT TEST REALISM:** Automated Python BeautifulSoup tests must not be claimed as proving JavaScript execution. Tests must either execute real JS adapters in a Firefox test profile or be explicitly labeled as offline HTML fixture schema tests.
