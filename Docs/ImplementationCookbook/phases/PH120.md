# Phase Packet: PH-120 — Specialized Browser Site Adapters

## 1. Purpose
Implement specialized semantic DOM content script adapters for major supported sites: Google Search, Amazon, ChatGPT, Claude, and Gemini. Adapters rely on resilient semantic selectors and accessibility roles. If site markup changes, adapters fail gracefully (`ADAPTER_OUTDATED`) without granting arbitrary model browsing or crashing the daemon.

## 13. Exact Algorithms

### Algorithm: Semantic Result Extraction (Google Search)
1. Verify `window.location.origin === "https://www.google.com"`.
2. Query organic search containers using semantic selectors:
   - Primary: `div.g, div[data-hveid]`
   - Fallback: `[role="heading"][aria-level="3"]`
3. For each matched item (up to 5):
   a. Extract title text from `h3`.
   b. Extract target URL from anchor `a[href]`.
   c. Extract snippet from `div[data-sncf]`, `span.aCOpRe`, or adjacent text block.
4. If zero results matched:
   a. Call `handle_outdated_dom()`.
   b. Return `status: "ADAPTER_OUTDATED"`, `results: []`.
5. Return extracted array (max 5 results).

### Algorithm: AI Site Turn Extraction (ChatGPT, Claude, Gemini)
1. Verify origin matches `https://chatgpt.com`, `https://claude.ai`, or `https://gemini.google.com`.
2. Query assistant message turn elements:
   - ChatGPT: `[data-message-author-role="assistant"]`
   - Claude: `[data-testid="assistant-message"], div.font-claude-message`
   - Gemini: `model-response, .model-response-text`
3. Extract text from the latest assistant turn. Truncate at 10,000 characters.
4. If selector fails, return `ADAPTER_OUTDATED`.

## 14. Reference Implementation
```javascript
// extension/firefox/adapters/base.js
class BaseAdapter {
  handle_outdated_dom() {
    return {
      status: "ADAPTER_OUTDATED",
      results: [],
      error: "Website DOM markup has changed; adapter needs updating."
    };
  }
}
```

## 15. Concurrency Model
- Synchronous DOM inspection within tab event loop.

## 16. Cancellation Behavior
- Content script execution is non-blocking to browser UI; cancels if tab closes.

## 17. Timeout Behavior
- 2.0s maximum extraction execution time per tab.

## 18. Retry/Idempotency Behavior
- Extraction is strictly read-only and idempotent.

## 19. Error Behavior
- On failure, adapter returns `ADAPTER_OUTDATED`. Daemon falls back to generic text extraction or informs user.

## 20. Security Invariants
- **Primary Enforcement:** Content script verifies `window.location.origin` before querying DOM.
- **Fail-Closed:** Missing selectors never trigger indiscriminate full-DOM scraping or arbitrary JS execution.

## 21. Resource Limits
- Extraction capped at 5 search items or 10,000 chars of assistant response.

## 22. Secrets/Privacy Behavior
- Search queries and extracted titles are routed back through native bridge; cookies and storage tokens are never inspected.

## 23. Failure Cases
- Site layout completely redesigned: Catches missing selector, returns `ADAPTER_OUTDATED`, avoids throwing uncaught JS error.
