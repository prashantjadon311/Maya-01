# Phase Packet: PH-050 — Interactive Approval Broker & Native Popup

## 1. Purpose
Implement the `ApprovalBroker` to handle sensitive action authorization requests (`PolicyDecision.ASK_USER`). Guarantees that any action requiring user confirmation is paused until explicitly approved via an independent native popup. Introduces single-use `ApprovalGrant(source="HUMAN_ALLOW_ONCE")` cryptographically bound to an immutable SHA-256 payload hash, atomic `consume_grant` under lock, and typed `ExecutionAuthorization` carrying `ProcessExecutionConstraints`. Fails closed on denial, timeout, popup crash, or capacity exhaustion. Establishes the initial `app/lifecycle.py` foundation.

    ALLOW_ONCE = "ALLOW_ONCE"

class ExecutionAuthorization(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")

    trusted_risk: RiskLevel
    process_constraints: ProcessExecutionConstraints | None = None

## 13. Security Boundaries & Invariants
1. **PENDING IS NEVER CONSUMABLE:** Only `ApprovalGrant` objects in `_grants` can be consumed. `PendingApproval` objects cannot execute.
2. **ATOMIC CONSUMPTION:** `consume_grant()` validates existence, expiry, and recomputes SHA-256 canonical hash under an `asyncio.Lock`. On mismatch, the grant is immediately invalidated and popped, returning `False`. On match, the grant is popped and returns `True`. Replay attempts return `False`.
3. **FAIL-CLOSED CAPACITY:** If pending requests reach `MAX_PENDING_APPROVALS = 10`, `request_decision` fails closed immediately with `PopupDecision.DENY`. It NEVER evicts an active pending approval.
4. **HUMAN APPROVAL HARD CONSTRAINTS:** Human approval NEVER bypasses permanent path denial, traversal checks, strict argv parsing, trusted executable resolution, or output limits.

## 23. Edge Cases & Failure Modes
- Popup process fails to launch: Fails closed to `PopupDecision.DENY`.
- User closes popup window without selecting Allow: Treated as `PopupDecision.DENY`.
- Timeout expires: Pending request popped; fails closed to `PopupDecision.DENY`; no grant is minted.
- Daemon restart / crash: All pending approvals and grants cleared from RAM; unexecuted actions cannot proceed.
